# WA Downloader

تطبيق أندرويد يحمّل الملفات التي تصل إلى واتساب تلقائياً، مع دمج الأجزاء المتتالية في ملف واحد.

- الحفظ في `Download/my downloading file` (الاسم قابل للتغيير من الإعدادات)
- تسجيل دخول مرة واحدة برمز الربط، والجلسة تُحفظ
- التحميل واحداً تلو الآخر مع فاصل عشوائي (3–10 ثوانٍ افتراضياً)
- دمج `file-part1`, `file-part2`… في `file-merged` (يدوي أو تلقائي)

## البنية
- `nodejs-project/` : محرك واتساب (Baileys) يعمل داخل التطبيق عبر nodejs-mobile
- `app/` : واجهة Kotlin + Compose، وخدمة في المقدمة، وجسر JNI
- `.github/workflows/build.yml` : يبني الـ APK تلقائياً

## البناء
ارفع المشروع إلى GitHub فيبدأ الـ workflow وحده. بعد انتهائه:
**Actions ← آخر تشغيل ← Artifacts ← WADownloader-debug** (ملف APK).

## ملاحظات
- Baileys غير رسمية وقد يحظر واتساب الحساب؛ استخدم رقماً لا تخسر منه.
- الملف يُحمَّل أولاً في مجلد التطبيق ثم يُنسخ للتنزيلات، فيلزم ضعف حجمه مؤقتاً.
- الدمج يوصل القطع الخام فقط (مثل .001 أو part1)، ولا يفك RAR/ZIP.
